Question

When a differential-expression study has few replicates, how much of what it reports would another study of the same size find again, and how much of the full truth does it recover? Degen & Medo (2025) answer this by repeatedly drawing small random cohorts from large RNA-seq data sets. This site reproduces that design on one of their data sets.

Methodology: what was actually done

  • Data. TCGA breast cancer, Basal vs Luminal A, 126 + 126 tumours, 18,188 genes (the authors' BSLA data set, taken from their repository, not re-downloaded).
  • Cohorts. For each N in {3, 4, 5, 6, 7, 8, 9, 10, 12, 15} per group, 100 random cohorts drawn without replacement. Cohorts at the same N are independent draws and can share samples, as in the paper. Every draw is seeded from (seed, N, trial) so reruns are identical.
  • Reference ("truth"). The full 252-sample analysis. Two versions: the authors' own full-data DESeq2 result (2,039 genes), and the same pipeline as ours on all samples (1,852 genes).
  • Calling genes. Covariates tumour purity and age, formal test of |log2FC| > 1, Benjamini-Hochberg FDR below 5 % (primary setting; sensitivity over no filter / 0.5 / 1.0 and FDR 1 % / 5 % in the filters above).
  • Metrics. Precision and recall against the reference. Replicability is the Jaccard index between the gene lists of two cohorts, over all pairs at a given N, summarised by the median (0 if either list is empty). Rank agreement is Spearman correlation of log2FC with full data.
  • Two engines. PyDESeq2 (Wald test, formal threshold, covariates) — closest match to the paper, ~1 min/cohort, so 10 cohorts per size (50 cohorts, 45 pairs per size). A numpy engine in the style of limma-trend ran all 1,000 cohorts in ~1 min; used for distributions, gene-level view and threshold sensitivity. It is conservative below ~8 per group.

Findings

  • 1. PyDESeq2 lands on the paper's numbers. At N = 5: precision, recall, replicability 0.84 / 0.15 / 0.20 vs published 0.84 / 0.14 / 0.19. At N = 10: 0.91 / 0.21 / 0.33 vs 0.90 / 0.25 / 0.30. With 10 cohorts per size these medians are noisy — agreement is good, not exact.
  • 2. Replicability stays low. PyDESeq2 median overlap: 0.14 at N = 3, 0.20 at 5, 0.29 at 7, 0.33 at 10, 0.41 at 15. Two 15-vs-15 studies agree on fewer than half the genes either reports.
  • 3. Small studies are precise but incomplete. Precision 0.71 at N = 3, ≥0.84 from N = 5. Recall 0.14 at N = 3, only 0.35 at N = 15 — mostly real genes, but most missed.
  • 4. Which genes survive is not random. At N = 10, the 128 reference genes (of 1,852) called by ≥half the cohorts have median |log2FC| 4.78 vs 2.02 for the whole list. Small cohorts find very large effects.
  • 5. Not a threshold artefact. Across six settings (no filter / 0.5 / 1.0; FDR 1 % / 5 %), fast-engine replicability at N = 10 stays 0.28–0.35.
  • 6. Engine caveat. Fast engine calls no genes in 64 %, 47 %, 21 % of cohorts at N = 3, 4, 5, pinning its replicability near 0 there. At N = 7, 10, 15 it is within 0.04 of PyDESeq2. Its small-N curve should not be read as biology.

How well do the engines agree with the authors?

R is not available in the environment this was built in, so the paper's DESeq2 and edgeR could not be run. Two stand-ins were used, and both were checked against results the authors published in their repository.

  • Fast engine (blue): a numpy re-implementation in the style of limma-trend with a formal fold-change test and the same covariates. It runs 1,000 cohorts in about a minute, but it is conservative below about 8 samples per group, so its small-cohort numbers understate what DESeq2 or edgeR would find.
  • PyDESeq2 anchor (orange): the Python port of DESeq2 with covariates and a formal |log2FC| > 1 test, the closest available match to the paper's main pipeline. It takes minutes per cohort here, so only 10 cohorts per size (45 cohort pairs) were run and the ranges are wide.

What this does and does not show

  • One data set of 18. Gene-set enrichment, the paper's second analysis, is not reproduced. The GEO data sets are outside this environment's network allowlist.
  • The reference ("truth") is the full-data analysis, and the cohorts are subsets of those same samples, as in the paper. Precision at large N is therefore somewhat flattering.
  • Replicability is the Jaccard index between the DEG lists of two cohorts, taken over all pairs of random cohorts at a given N and summarised by the median. Cohorts at the same N can share samples. The list of cohort sizes (3 to 15, ten values) is an assumption.
  • "Published" values come from the authors' results table in their repository (row BSLA), which stores N = 5 and N = 10 only. Column meanings were not cross-checked against the paper's Table 1.
  • Anchor and published points exist for the primary setting only (|log2FC| > 1, FDR 5 %).

Practical reading

For a study of this kind (a heterogeneous tumour comparison), 5 to 10 replicates per group yields gene lists that are mostly correct but cover only about a fifth to a quarter of the full signal, and a repeat study would find only about a fifth to a third of the same genes. The paper's bootstrap tool (pdegen/BootstrapSeq) is the authors' suggested way to estimate this for your own small data set.
